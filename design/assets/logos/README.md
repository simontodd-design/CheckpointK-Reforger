# CK Logos

Save your CK brand logo files here. Required variants:

## Master
- `ck-logo-master.png` — the full version with energy ring on pure black
  (the version you shared 2026-05-31). Highest resolution available
  (2048×2048+ recommended). Used as source for all other variants.
- `ck-logo-master.svg` — vector version if/when available. SVG always
  preferred for UI use.

## Variants to produce (Phase 0 designer sprint)
- `ck-logo-tight.svg` — monogram only, no energy ring, for small sizes
- `ck-logo-mono.svg` — single-color frost-50, no glow, for UI inline use
- `ck-logo-icon-512.png` — app icon, 512×512, with energy ring
- `ck-logo-icon-256.png`
- `ck-logo-icon-128.png`
- `ck-logo-icon-64.png`
- `ck-logo-icon-32.png` (tight variant — energy ring loses detail)
- `ck-logo-icon-16.png` (tight variant — monogram only)
- `ck-favicon.ico` — Windows multi-resolution

## Usage rules
See `design/brand-bible.md` §3 "The logo itself" — always on pure black,
never recolored, minimum clear space + sizes.

# Code of Conduct

Checkpoint K is a small project. The rules are simple:

1. **Be kind.** Disagree about code or design without personal attacks.
2. **Stay on topic.** This is a survival game project, not a venue for
   unrelated political, religious, or ideological argument.
3. **No harassment, threats, slurs, or hate speech.** Zero tolerance.
   First offence is a warning, second is a ban.
4. **Respect privacy.** Don't dox players, contributors, or admins.
   Don't share private DMs without consent.
5. **Cheating is forbidden.** Any tooling intended to bypass game
   mechanics, anti-cheat, or CK's authority model results in a
   permanent ban from servers and the GitHub project.

## Enforcement

Reports go to **simontodd.design@gmail.com**. The project owner is the
sole moderator at v1. As the community grows, moderation expands.
